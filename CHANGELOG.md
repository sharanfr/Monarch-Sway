# [v1.0] - Initial Public Release

The first public release of Monarch-Sway.

Monarch-Sway was created as a minimal, modular and productivity-focused SwayWM desktop inspired by Material Expressive styling and Omarchy-like simplicity.

---

## ✨ Added

### Desktop

- Modular Sway configuration
- Custom Waybar
- Wofi launcher
- Foot terminal configuration
- Mako notification system
- Fastfetch branding

### Workflow

- Wallpaper Picker
- Performance Profile selector
- Power Menu
- Screenshot workflow
- Screen recording workflow
- Blur lockscreen integration

### User Interface

- Soft blue Monarch theme
- Transparent Waybar
- Custom Wofi styling
- Unified desktop appearance

### Philosophy

- Minimal
- Modular
- Lightweight
- Productivity-first
- Keyboard-driven workflow
- Consistent desktop experience

---

## 🎯 Project Goals

Monarch-Sway was built around one principle:

> **Minimalism without sacrificing workflow.**

Every feature aims to improve everyday usability while keeping the desktop lightweight, fast and visually consistent.
